# สามก๊ก: นอกด่านรุกราน — Online Edition

เวอร์ชันเว็บของบอร์ดเกมการ์ด "สามก๊ก: นอกด่านรุกราน" (Samkok Card Games) เล่นออนไลน์กับเพื่อนในวง LAN/WiFi เดียวกัน ไม่ต้อง deploy ขึ้นอินเทอร์เน็ต

## วิธีเริ่มเล่น (สำหรับเจ้าของเครื่อง/โฮสต์)

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
cd webapp
npm install       # ครั้งแรกครั้งเดียว
npm run build     # build หน้าเว็บ (ทำใหม่ทุกครั้งที่แก้โค้ด client)
npm start         # เปิดเซิร์ฟเวอร์
```

เมื่อรันแล้วจะเห็นข้อความประมาณนี้:

```
On this computer:  http://localhost:3001
For friends on your WiFi/LAN:  http://192.168.1.5:3001
```

- ตัวเอง (โฮสต์) เข้าเล่นผ่าน `http://localhost:3001`
- เพื่อน**ที่ต่อ WiFi/LAN วงเดียวกัน**เปิดเบราว์เซอร์ (มือถือ/โน้ตบุ๊คก็ได้) แล้วพิมพ์ที่อยู่ `http://192.168.x.x:3001` ตามที่ขึ้นในคอนโซล
- ถ้าเข้าไม่ได้ ให้เช็คไฟร์วอลล์ของ Windows (อาจต้องอนุญาต Node.js ให้เข้าถึงเครือข่ายส่วนตัว)
- กด "สร้างห้องใหม่" เพื่อได้รหัสห้อง 4 ตัวอักษร แล้วส่งรหัสให้เพื่อนกด "เข้าร่วมห้อง"
- เมื่อทุกคนเข้าห้องครบ (2–10 คน) โฮสต์กด "เริ่มเกม"

รีเฟรชหน้าเว็บได้โดยไม่หลุดจากเกม (จำที่นั่งไว้ให้อัตโนมัติผ่าน localStorage ของเบราว์เซอร์นั้นๆ)

## ระหว่างพัฒนา (dev mode)

```bash
npm run dev:server   # terminal 1
npm run dev:client   # terminal 2, เปิดที่ http://localhost:5173
```

## ทดสอบเอนจิ้นอัตโนมัติ

มีสคริปต์บอทจำลองผู้เล่นหลายคนเล่นกันเองแบบสุ่ม เพื่อเช็คว่า engine ไม่ error (รันเซิร์ฟเวอร์ค้างไว้ก่อน แล้วรันสคริปต์นี้ในอีก terminal):

```bash
npm start                 # terminal 1
node bot_test.mjs         # terminal 2 (แก้ NUM_BOTS ในไฟล์เพื่อเปลี่ยนจำนวนผู้เล่นทดสอบ)
```

## โครงสร้างโปรเจกต์

- `server/src/data/*.json` — ข้อมูลการ์ดทั้งหมด (ขุนพล 25, บทบาท 5, เสบียง 11 แบบ) แปลงมาจากรูปถ่ายการ์ดจริงใน `../Samkok/`
- `server/src/engine/` — กติกาเกมทั้งหมด (state machine, การต่อสู้, ความสามารถขุนพล/การ์ด, เงื่อนไขชนะ)
- `server/src/rooms.js` + `index.js` — ห้องเล่น/lobby ผ่าน Socket.IO และเสิร์ฟหน้าเว็บ
- `client/` — หน้าเว็บ React

## ⚠️ จุดที่ผมตีความ/สันนิษฐานเอง (ควรเช็คกับกล่องจริงถ้าอยากได้กติกาที่แม่นยำ 100%)

กฎที่ให้มามีแค่ 2 หน้า (หลังกล่อง) ซึ่งสรุปสั้นมากเทียบกับความซับซ้อนของขุนพล 25 ใบ ผมเลยต้องตัดสินใจเองในบางจุด — เล่นไปก่อนได้เลย แล้วถ้าอยากปรับให้ตรงกับกล่องจริงมากขึ้น บอกผมได้ทุกจุด:

1. **ตารางจำนวนการ์ดบทบาทต่อผู้เล่น 7 คน** — ตัวเลขในรูปรวมกันได้ 8 ไม่ใช่ 7 (น่าจะอ่านตัวเลขในตารางผิดพลาดจุดใดจุดหนึ่งเพราะแสงสะท้อน) ผมปรับ "ฝ่ายแม่ทัพ" จาก 2 เหลือ 1 ให้ผลรวมตรง — ดู `server/src/data/roles.json` → `countsByPlayerCount["7"]`
2. **โยจิ๋น (g4)** — ไอคอนในรูปดูเหมือนพาสซีฟ (∞) แต่ข้อความบนการ์ด ("ใช้ได้เฉพาะตาเราเท่านั้น") อ่านแล้วเหมือนความสามารถแบบกดใช้เอง เลยจัดเป็นประเภท "action" แทน
3. **ชื่อการ์ดอุบาย 3 ใบที่แสงสะท้อนจนอ่านไม่ชัด** (t2, t3, t6) — ตั้งชื่อ "ไท่ผิงฟื้นพลัง"/"ไท่ผิงหุ่นดิน"/"สายฟ้าฟาด" ให้พอเดาได้ตามภาพประกอบ+ความเชื่อมโยงกับความสามารถเตียวก๊ก (ค้นหาการ์ด "ไท่ผิง")
4. **รองแม่ทัพหลายคน** — ผมให้ผู้เล่นสะสมขุนพลในค่ายได้เรื่อยๆ (จากการจ้างซ้ำ) แต่ใช้ความสามารถได้แค่ตำแหน่ง "แม่ทัพ" ตำแหน่งเดียวเท่านั้น (สลับเข้ามาทางปุ่ม "สลับแม่ทัพ") — ขุนพลอื่นในค่ายถือเป็นตัวสำรอง ไม่มีผลอะไรจนกว่าจะถูกสลับเข้ามา
5. **จำนวนทหารราบ/นายพลในกล่องจริง (ของจำกัด 50/23 ใบ)** — เวอร์ชันนี้ไม่จำกัดจำนวนทหารราบทั้งหมดในเกม (แค่นับเป็นตัวเลขต่อผู้เล่น) เพราะเป็นข้อจำกัดทางกายภาพของกล่องจริง ไม่ใช่กติกาเชิงกลยุทธ์
6. ชื่อขุนพลบางตัว (เช่น ม้าอ้วนยี่, โลติด, ตั๊กอิ๋ว, เขาเฉียว) ถ่ายภาพมาไม่ชัดเรื่องตัวสะกด/การอ้างอิงประวัติศาสตร์ที่แน่นอน — ไม่กระทบกติกาการเล่น เป็นแค่ชื่อ

พิมพ์บอกผมได้เลยถ้าเจออะไรเล่นแล้วรู้สึกไม่ตรงกับกล่องจริง จะแก้ให้ตรงขึ้นเรื่อยๆ
